IaaS - Infrastructure as a Service
PaaS - Platform as a Service
SaaS - Software as a Service

IaaS (Infraestrutura como Serviço): Você aluga a infraestrutura (servidores, armazenamento, rede) do provedor. Você é responsável pelo sistema operacional, máquinas virtuais,servidores,armazenamento,redes,discos,data centers físicos. Google Cloud

google Cloud:
Compute Engine
Persistent Disk
VPC


PaaS (Plataforma como Serviço): Você aluga a plataforma (servidores, armazenamento, rede, sistema operacional, middleware). Você é responsável apenas pelas aplicações e dados. Ex: Google App Engine, Google Cloud Run, Google Kubernetes Engine, Google Cloud Functions, Heroku, AWS Elastic Beanstalk, Microsoft Azure App Service.

SaaS (Software como Serviço): Você aluga o software pronto. Você não é responsável por nada além de usar o software. Ex: Google Workspace, Microsoft 365, Salesforce.

IaaS → Quero SERVIDOR.

PaaS → Quero PROGRAMAR.

SaaS → Quero USAR.

Principal diferença entre IaaS, PaaS e SaaS
